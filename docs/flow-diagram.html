🔄 本次改动
去掉的：
• 得到大脑（biji.com）API — 不稳定，已删除
• 5 个碎条件判断（textIsJustUrl / textIsMissing / textTooShort / isShareText / isVideoPlatform）— 合并为 2 层判断
• isVideoPlatform 里的 youtube/douyin 误匹配 — 已移除

新增的：
• 抖音提取器 — TikHub /api/v1/douyin/web/fetch_one_video_by_share_url
• 微博提取器 — TikHub /api/v1/weibo/web_v2/fetch_post_detail
• 浏览器正文兜底 — 全失败时电脑端用 Chrome 插件抓的正文
• 手机端/电脑端区分 — 手机端跳过"正文够不够"判断

简化的判断逻辑：
旧版 5 个条件交叉判断 → 新版 2 层：① URL 是不是已知平台 ②（未知平台时）正文够不够
